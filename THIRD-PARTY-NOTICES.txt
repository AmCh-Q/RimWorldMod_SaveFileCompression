Third-party code distributed with SaveFileCompression
=====================================================

The 1.2-1.6 build merges the assemblies below into a single file,
1.2-1.6/Assemblies/SaveFileCompression_Common.dll, with ILRepack.

ZstdSharp.Port 0.8.6
  Copyright (c) Oleg Stepanischev
  License: MIT
  https://www.nuget.org/packages/ZstdSharp.Port
  Its types are merged but deliberately kept public, in the ZstdSharp
  namespace, because the mod's own code calls them.

The following .NET Foundation packages are merged as well:

  Microsoft.Bcl.AsyncInterfaces 5.0.0
  System.Buffers 4.5.1
  System.Memory 4.5.5
  System.Numerics.Vectors 4.5.0
  System.Runtime.CompilerServices.Unsafe 6.0.0
  System.Threading.Tasks.Extensions 4.5.4

  Copyright (c) .NET Foundation and Contributors
